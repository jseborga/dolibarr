# Modulo PettyCash

Este módulo permite manejar cajas chicas para usuarios. Se pueden asignar saldos iniciales, registrar gastos con documentos adjuntos y vincularlos con facturas de clientes.

## Uso básico
1. Abra una cuenta de caja chica desde el menú Finanzas.
2. Suba los recibos escaneados en la pestaña de documentos.
3. Verifique cada descargo para cambiar el estado a *Verificado*.
4. Cuando todos los descargos estén listos, genere la factura correspondiente.
